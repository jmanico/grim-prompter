Put client material in the matching folder, then run engage.py scan and extract.

design/         architecture and design documents, security requirements, data flow descriptions
diagrams/       architecture, network and data-flow diagrams (PDF, PNG, SVG, VSDX, draw.io)
vendor/         third-party product documentation, security whitepapers, SOC 2 or ISO reports, contracts
workshops/      workshop and validation-call transcripts or notes (VTT, SRT, DOCX, TXT, MD)
configuration/  configuration exports and screenshots that show how something is actually set up
code/           one folder per repository copy, when source code is available
other/          anything else
