# Grim Prompter Catalog

Prepare evidence, choose a bounded analysis, or review a supplied threat model.

**Choose:** Select the narrowest role whose purpose matches the job. **Run:** Ask your coding agent to run it under the [agent runbook](runbook.md), or use the `threat-model` skill. The agent gathers the evidence that file requests from your project, writes the output its contract defines to the run folder, and respects its refusal boundary.

**Technology boundary:** These roles describe workflow and outcomes. When implementation rules depend on a named technology or version, resolve the applicable pack first and keep those rule details outside the utility prompt.

**Start here:** Run it on [your project](start-here.md#run-it-on-your-project), then choose a quick architecture role or its six-stage path. Use the optional [evidence guide](helpers/evidence-guide.md) to gather a bundle, or the [challenger](helpers/model-challenger.md) to review an existing envelope. The shared [quick-analysis pattern](reference/quick-analysis-pattern.md) and [ordered six-stage patterns](reference/README.md) are also available.
